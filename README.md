# 🏨 Booking API (Сервис бронирования жилья)

## 📖 Описание
REST API для сервиса поиска и бронирования жилья. Проект предоставляет масштабируемый бэкенд для управления объектами недвижимости, поиска доступных вариантов для проживания, обработки бронирований и фоновой генерации документов.

## 🛠 Технологический стек
- **FastAPI** — высокопроизводительный асинхронный веб-фреймворк для создания API.
- **SQLModel** — ORM для взаимодействия с базой данных, объединяющая возможности SQLAlchemy и Pydantic.
- **PostgreSQL** — надежная реляционная база данных для хранения пользователей, отелей и истории броней.
- **Redis** — in-memory хранилище для кэширования и работы в качестве брокера сообщений.
- **Celery** — распределенная очередь задач для выполнения фоновых процессов (например, генерация документов и отправка уведомлений).

## 🚀 Основной функционал
- 🔍 **Поиск и фильтрация:** Выборка жилья по датам и параметрам с оптимизацией запросов.
- 📅 **Управление бронированиями:** Создание, отмена бронирований, строгая проверка на пересечение дат проживания.
- 📄 **Фоновые задачи:** Асинхронное создание подтверждающих документов (счетов/чеков) с использованием Celery.
- ⚡ **Кэширование:** Оптимизация работы и снижение нагрузки на БД при помощи Redis.

## ⚙️ Установка и запуск

### Предварительные требования
- Python 3.10+
- Установленные сервисы PostgreSQL и Redis (либо Docker и Docker Compose).

### Запуск через Docker (Рекомендуется)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Nikita-tg-python/booking.git
   cd booking
   ```
2. Создайте файл `.env` (скопируйте из `.env.example`, если есть) и укажите ваши учетные данные БД и Redis.
3. Запустите сборку и старт контейнеров:
   ```bash
   docker-compose up -d --build
   ```

### Локальный запуск (без Docker)
1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # Для Windows: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Убедитесь, что PostgreSQL и Redis запущены локально. Настройте подключение в файле `.env`.
5. В отдельном окне терминала запустите воркер Celery:
   ```bash
   celery -A app.core.celery worker --loglevel=info
   ```
6. Запустите API-сервер:
   ```bash
   fastapi dev
   ```
